# Forwarded skill

The maintained `r-package-setup` implementation is part of
[wise-writing](https://github.com/DeepWaterIMR/wise-writing/tree/main/skills/r-package-setup).
Use that skill for package-loading guidance. If it is not already installed, read
`academic_writing_path` from `~/.wise-writing/config.json` (falling back to
`~/.academic-writing/config.json`) and open `<academic_writing_path>/skills/r-package-setup/SKILL.md`.

This file remains at its former BAIT path for compatibility; it is not a second implementation.
